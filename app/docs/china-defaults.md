# 语言、金额和时间

新站点的服务、事件和通知使用简体中文。客户中心首次打开时显示简体中文，用户选择的其他语言保存在当前浏览器。管理端显示中文。

新账本以人民币计价。余额、套餐价格、支付金额和退款均以元记录，金额保留两位小数。客户中心从 `GET /shm/v1/system/auth` 的 `data[0].billing.currency` 读取账本币种。原有站点仍按自己的账本币种收付款，修改显示符号无法换算历史金额。

应用进程和 MySQL 会话读取现有的 `TZ`，默认为 `Asia/Shanghai`。MySQL 使用命名时区表。需要核对时，在应用所用的数据库连接中执行以下查询。

```sql
SELECT @@session.time_zone, NOW(), UTC_TIMESTAMP();
```
