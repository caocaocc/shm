# 流量套餐与扣费记录

在套餐的服务设置里填写 Remnawave 配额。例如每期 10 GiB、按月重置的套餐使用以下设置。

```json
{
  "remnawave": {
    "traffic_limit_bytes": 10737418240,
    "traffic_limit_strategy": "MONTH"
  }
}
```

正整数额度启用整期预付。购买和续费使用现金及该套餐允许抵扣的奖励，余额须足以付清全期。换套餐按目标套餐决定付款条件。普通套餐继续使用 SHM 原有的信用、奖励和部分账期设置。零额度或省略额度表示无限流量，重置策略只决定面板计数周期。

每次付款把当期额度和起始读数记在对应的扣款记录。开通时尚无面板账号的服务，在 CREATE 成功并绑定服务器后补读起点。默认面板用户名为 `us_<用户服务编号>`，已有服务可在自己的 `settings.data.username` 指定绑定账号。

提前终止时，SHM 按原账期算法计算时间比例，并与「本期用量 ÷ 购买时的额度」比较。消费比例取两者较大值，最高 100%。现金与奖励各自按原支付金额计算到分。例如实际支付 60 元现金和 20 元奖励，时间消耗 20%、流量消耗 60%，则退 24 元现金和 8 元奖励。禁止退款和全额退款沿用套餐原设置。

面板在期中重置后，只计重置后的流量。临时读不到可信计数时，可退费的提前终止或立即换套餐会等待重试。自然到期可照常续费，前一期的未知用量记为空。暂停服务保留原账期。

客户可在扣费记录查看每笔的额度和结清用量。尚未结清或读数缺失时，界面应区分未知用量与确认使用了 0 字节。
