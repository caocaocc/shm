# 易支付商户与订单

全新站点启动后，管理员可在「支付系统 → 易支付 → 配置」录入商户。已有原版 SHM 3.7.0 站点可使用[独立安装包](epay-standalone.md)。

## 设置默认商户

在「设置 → 配置 → 常规」核对钱包币种与公网 API 根地址。易支付向 CNY 账本入账。已有业务数据的站点变更币种前，应核对余额、套餐和历史付款的计价单位。

在主配置中填写支付服务商的 HTTPS 网关根地址和商户号 PID。MD5 商户填写密钥，RSA 商户填写商户私钥和平台公钥。已配置的凭据显示设置状态。同一商户同一签名方式的密钥留空时沿用已保存的值。

| 签名方式 | 网页跳转 | API 下单 |
|---|---|---|
| MD5 | submit.php | mapi.php |
| RSA | api/pay/submit | api/pay/create |

## 设置充值页

填写客户能识别的名称，在需要开放的渠道勾选「在充值页显示」。需要同时提供支付宝和微信时，在「副本 → 创建副本」勾选「支付方式」，为两个副本分别选择 alipay 和 wxpay。未单独填写的选项继承主配置，可用「添加字段」调整。客户重新打开充值窗口即可获取当前可用渠道。

## 通知、返回与查单

SHM 根据自己的公网 API 根地址生成异步通知入口 `/shm/pay_systems/epay_notify.cgi` 和浏览器返回入口 `/shm/pay_systems/epay_return.cgi`。模块按下单时记录的商户资料核对付款。验证通知和查单得到的商户、单号、金额和付款状态后，同一笔订单对应一次钱包入账。关闭渠道后，历史订单仍可接收通知和查单。

付款返回页面可查看本地状态。待确认订单应按原订单号查单。核对收款时，可同时检查网关订单、SHM 订单状态及对应的钱包流水。

备份数据库时一同保存应用数据卷中的 `/app/data/epay/key`。已有商户密文和历史订单需要原密钥。新装站点首次填写商户时创建密钥，独立安装器完成安装时也会准备密钥。
